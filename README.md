# Timeline 

Тестовый проект: интерактивная временная шкала (Timeline) на **React**, с круговым выбором и адаптивным слайдером **Swiper**.

## Технологии

- React 19
- TypeScript
- Swiper 12
- Webpack 5
- Sass/SCSS

## Установка и запуск

1. Клонируем репозиторий:

```bash
git clone https://github.com/mrjohnny-code/timeline.git
cd timeline-project
```

2. Устанавливаем зависимости

```bash
npm install
```

3. Запуск локального сервера

```bash
npm run start
```
